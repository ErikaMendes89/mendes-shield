# Governance

Mendes Tech is the initial maintainer. The project owner makes final decisions about releases, licensing, architecture, and security disclosures.

## Decisions and changes

Substantial architectural decisions should be discussed and recorded as an [Architecture Decision Record](docs/adr/README.md) before the related integration work begins. Proposals should state context, options considered, consequences, security and privacy implications, and acceptance criteria.

Changes should be reviewed through pull requests with reproducible verification evidence. A summary produced by an automated agent is not a substitute for inspecting the change and its evidence. Production blocking behavior requires explicit project-owner approval and is outside the current foundation scope.

## Project status

The license and contributor terms are pending owner approval. Code contributions are paused until those decisions are published. The public roadmap describes intended work, not commitments or completed capabilities. This repository does not imply security assurance, release certification, or a service-level agreement.
