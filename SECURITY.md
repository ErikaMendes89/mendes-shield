# Security Policy

## Supported versions

There is no production release or supported security product. The repository currently contains a development API foundation only; it does not detect or mitigate attacks.

## Reporting a vulnerability

Do not publish exploitable details, credentials, or private telemetry in public issues. Use GitHub Private Vulnerability Reporting if it is enabled for this repository. Otherwise, ask the maintainer for a private reporting channel without posting exploit material publicly.

Please include the affected commit or version, impact, and a minimal authorized reproduction when it is safe to share privately. Do not test systems you do not own or have explicit permission to assess.

The project does not promise a security response SLA. No privacy, detection, or mitigation design described in the documentation should be treated as implemented or independently validated unless the repository contains the corresponding code and evidence.
